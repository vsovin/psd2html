# Концепция промо-сайта VirshkeTech.com

## Идея разделения трафика (главная задача ТЗ)

Проблема текущего сайта — весь контент в одной куче: клиент с Fanuc видит
рассказ про ручной станок и уходит. Решение — три изолированных посадочных
потока, каждый под свою рекламную кампанию в Директе:

1. **Профессиональные ЧПУ** (Fanuc, Siemens, GSK, Mazak, Okuma, Haas) → `cnc-pro.html`
   Ограниченный функционал, подключение через блок киоск / импульсные драйверы, 370 000 ₽.
2. **ЧПУ начального уровня** (DDCS, Mach3, LinuxCNC, Inctra, Pumotix) → `cnc-lite.html`
   Полный функционал, реле / StepDir / ModBus, 340 000 ₽.
3. **Ручные станки** → `manual.html`
   Полный функционал с ручным управлением, «просто установил и работай», 370 000 ₽.

Каждая страница начинается с hero «под аудиторию» — человек из рекламы сразу
узнаёт себя. Если он попал не на свою страницу, **переключатель аудитории**
(три пилюли в sticky-header на всех страницах) позволяет за один клик
перейти куда нужно. Активная пилюля подсвечивается синим бренда (#0B3C6B).

Общий путь конверсии для всех трёх потоков:
`лендинг → калькулятор комплектации (/calculator.html) → форма заказа (/order.html) → /thanks.html`.
Конфигурация из калькулятора передаётся в форму через localStorage
(ключ `virshke_config`) и показывается клиентом как сводка заказа.

## Почему светлая тема на Bootstrap 5.3

- Промышленная B2B-аудитория ожидает «чистый» инженерный сайт; тёмная тема
  противоречит прямому запрету в ТЗ.
- Bootstrap 5.3 через CDN + один кастомный `style.css` = нулевая сборка,
  сайт открывается двойным кликом по HTML, правки доступны любому фрилансеру.
- Типовые компоненты (card, navbar, modal, form-validation, grid) закрывают
  90% задачи; фирменные цвета, пилюли и схема вынесены в префикс `.vt-*`.

## Файловая структура

```
/virshketech/
├── index.html              — главная: hero + развилка 3 потоков + характеристики + автоматизация + тизер калькулятора
├── cnc-pro.html            — посадочная: Fanuc/Siemens/Mazak
├── cnc-lite.html           — посадочная: Mach3/DDCS/LinuxCNC
├── manual.html             — посадочная: ручной станок
├── calculator.html         — конфигуратор: база (radio) + модули (checkbox) + SVG-подсветка + итог
├── order.html              — форма заявки + сводка из localStorage + маска телефона + модалка
├── thanks.html             — спасибо за заявку
├── products.html           — каталог с JS-фильтром по категориям
├── product-tfo-160.html    — детальная карточка ТФО-160 с хлебными крошками
├── contacts.html           — контакты, мессенджеры, заглушка карты, мини-форма
├── README.md               — инструкция: запуск, цены, контакты, логотип
└── assets/
    ├── style.css           — все кастомные стили (.vt-*) поверх Bootstrap
    ├── script.js          — CONFIG (цены), калькулятор, localStorage, маска, фильтр, пилюли
    └── img/
        ├── logo.svg        — основной логотип (цветной, для светлого фона)
        ├── logo-white.svg  — инверсный (белый, для тёмных блоков)
        ├── scheme.svg      — статичная SVG-схема станка с ТФО-160
        └── placeholder.svg — универсальная заглушка изображений
```

Общий header (логотип + 3 пилюли переключателя + телефон + «Оставить заявку»)
и footer (логотип, описание, контакты, меню, копирайт) скопированы на все
страницы без серверных include — как требует ТЗ (чистая статика).
