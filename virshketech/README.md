# VirshkeTech.com — промо-сайт ТФО-160

Статический многостраничный сайт: HTML5 + Bootstrap 5.3 (CDN) + vanilla JS. Без сборщиков и сервера.

## Структура

| Файл | Назначение |
|---|---|
| index.html | Главная: hero + развилка трёх аудиторий |
| cnc-pro.html | Посадочная: Fanuc / Siemens / Mazak |
| cnc-lite.html | Посадочная: Mach3 / DDCS / LinuxCNC |
| manual.html | Посадочная: ручной станок |
| calculator.html | Калькулятор комплектации |
| order.html | Форма заказа (+ сводка из калькулятора) |
| thanks.html | Спасибо за заявку |
| products.html | Каталог с фильтром по категориям |
| product-tfo-160.html | Детальная страница ТФО-160 |
| contacts.html | Контакты + форма «Задать вопрос» |
| assets/style.css | Кастомные стили поверх Bootstrap |
| assets/script.js | CONFIG с ценами, калькулятор, маска, фильтр |
| assets/img/ | Логотипы, схема станка, плейсхолдеры |

## Как открыть локально

Дважды кликнуть `index.html` — всё работает по протоколу `file://`.
Либо запустить мини-сервер для корректной работы всех браузеров:

```bash
cd virshketech
python3 -m http.server 8080
# открыть http://localhost:8080
```

## Как поменять цены

Все цены и названия базовых комплектаций и модулей вынесены в начало
файла `assets/script.js`, объект `CONFIG`:

```js
const CONFIG = {
  bases:   [ { key: "pro", name: "...", price: 370000 }, ... ],
  modules: [ { key: "chuck", name: "...", price: 120000 }, ... ]
};
```

Калькулятор, сводка заказа и форматирование (`Intl.NumberFormat`) берут
данные только оттуда. **Важно:** цены также продублированы в текстах
посадочных страниц (HTML) — при изменении обновляйте и их (поиск по числу).

## Как поменять контакты

Телефон, e-mail и адрес захардкожены в header/footer каждой страницы.
Замените одним.find/replace во всех файлах:

- `+7 (000) 000-00-00` и `tel:+70000000000` → реальный телефон
- `info@virshketech.com` → реальный e-mail
- `г. Москва, ул. Примерная, д. 0` → реальный адрес
- `https://t.me/` и `https://wa.me/` → ссылки на мессенджеры

## Как заменить логотип

Файлы-плейсхолдеры: `assets/img/logo.svg` (для светлого фона) и
`assets/img/logo-white.svg` (для тёмного footer). Замените содержимое
файлов на оригинальные SVG с теми же именами — вёрстка подхватит их
автоматически. Рекомендуемый размер области: ~170×44 px.

## Реальная отправка форм

Сейчас формы статичны: `sendOrder()` в `assets/script.js` пишет данные
в `console.log` и показывает модалку. Для подключения бэкенда замените
её на `fetch("/api/order", {...})` (место помечено комментарием).

## Требуется от заказчика (плейсхолдеры)

1. Оригинальный логотип в SVG (сейчас — плейсхолдер по описанию).
2. Точные характеристики ТФО-160 (в таблицах стоит «уточняется»).
3. Реальные цены модулей автоматизации (120/95/140/350 тыс. ₽ — предположение).
4. Телефон, e-mail, юридический адрес, реквизиты компании.
5. Ссылки Telegram / WhatsApp.
6. Фотографии станков и примеров подключения (placeholder.svg).
7. Текст политики конфиденциальности (ссылка в footer ведёт на `#`).
8. Отзывы клиентов на странице ТФО-160.
